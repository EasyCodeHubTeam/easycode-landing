# EasyCode — лендинг

Одностраничный сайт студии EasyCode: HTML + CSS + vanilla JS, без фреймворков и без сборки.
Три языка (русский, казахский, английский), тёмная и светлая темы, форма заявки → Telegram
через serverless-функцию Vercel.

## Структура

```
easycode-landing/
├── index.html            # разметка; русский текст прямо в HTML (для SEO и работы без JS)
├── css/style.css         # все стили; цвета, отступы и шрифты — переменные в :root
├── js/
│   ├── main.js           # тема, меню, анимации, ссылки, запуск модулей
│   ├── config.js         # ← ссылка на бота, email, соцсети
│   ├── i18n.js           # переключение языков
│   ├── i18n/ru.js        # ← все тексты сайта (русский — основной)
│   ├── i18n/kk.js        # ← казахский
│   ├── i18n/en.js        # ← английский
│   ├── portfolio.js      # карточки проектов из data/projects.json
│   └── form.js           # валидация и отправка формы
├── data/projects.json    # ← портфолио
├── assets/
│   ├── img/              # ← сюда кладёте картинки (см. «Как заменить картинки»)
│   ├── icons/sprite.svg  # иконки услуг и технологий (Simple Icons, CC0)
│   ├── favicon.svg
│   └── apple-touch-icon.png
├── api/lead.js           # Vercel-функция: заявка → Telegram
├── scripts/i18n.mjs      # проверка переводов (необязательно)
├── robots.txt, sitemap.xml
├── .env.example
└── .gitignore
```

## Локальный запуск

Открыть `index.html` двойным кликом не получится: браузер не даст загрузить модули и `projects.json`
с `file://`. Нужен любой локальный сервер.

**Только сайт (без отправки формы):**

```bash
npx serve .
# или
python3 -m http.server 8000
```

**Сайт вместе с функцией формы** — через Vercel CLI:

```bash
npm i -g vercel
cp .env.example .env      # впишите BOT_TOKEN и CHAT_ID
vercel dev                # http://localhost:3000
```

При первом запуске `vercel dev` спросит, привязать ли проект: можно создать новый.
Если спросит про фреймворк и команду сборки — выберите **Other** и оставьте сборку пустой.

## Telegram: токен и CHAT_ID

1. Откройте [@BotFather](https://t.me/BotFather) → `/newbot` → задайте имя и username.
   BotFather пришлёт токен вида `123456789:AA...` — это `BOT_TOKEN`.
2. Узнайте `CHAT_ID` — куда будут приходить заявки:
   - **в личку:** напишите своему боту `/start`, затем откройте в браузере
     `https://api.telegram.org/bot<BOT_TOKEN>/getUpdates` и найдите `"chat":{"id": ...}`;
   - **в группу:** добавьте бота в группу, напишите там любое сообщение и откройте тот же
     `getUpdates` — id группы отрицательный, например `-1001234567890`.
3. Токен храните только в `.env` локально и в переменных окружения Vercel.
   В браузер он не попадает: форма отправляет данные на `/api/lead`, а в Telegram пишет сервер.

Если токен случайно утёк — в @BotFather: `/revoke` → выберите бота → получите новый.

> Бот для заявок (`BOT_TOKEN`) и бот, на который ведут кнопки «Обсудить проект» (`botUrl` в
> `js/config.js`), могут быть одним и тем же ботом или разными.

## Деплой на Vercel

1. Залейте проект в GitHub-репозиторий.
2. На [vercel.com](https://vercel.com) → **Add New… → Project** → выберите репозиторий.
3. Framework Preset: **Other**. Build Command и Output Directory оставьте пустыми.
4. **Settings → Environment Variables** — добавьте:
   - `BOT_TOKEN` — токен от BotFather;
   - `CHAT_ID` — id чата для заявок;
   - `TURNSTILE_SECRET` — только если подключаете Cloudflare Turnstile.
5. **Deploy.** После изменения переменных нужен повторный деплой (Deployments → ⋯ → Redeploy).

`vercel.json` не нужен: Vercel сам раздаёт статику и превращает `api/lead.js` в функцию.

Проверить форму после деплоя: заполните её на сайте — сообщение должно прийти в чат.
Если не пришло — смотрите логи: Vercel → проект → **Logs**.

## Свой домен

1. Vercel → проект → **Settings → Domains** → **Add** → введите домен (например `easycode.kz`).
2. Vercel покажет DNS-записи. У регистратора домена добавьте:
   - для корневого домена — `A`-запись на IP, который показал Vercel;
   - для `www` — `CNAME` на `cname.vercel-dns.com`.
3. Подождите, пока DNS обновится (от минут до пары часов). SSL-сертификат выпустится сам.
4. Замените `https://easycode.kz` на свой домен в `index.html` (canonical, hreflang, Open Graph,
   JSON-LD), `robots.txt` и `sitemap.xml`. Поиск: `grep -rn "easycode.kz" .`

## Контакты и соцсети

Всё в `js/config.js`:

- `botUrl` — ссылка на бота. Кнопки «Обсудить проект» ведут на `botUrl?start=site`,
  чтобы в боте было видно, что клиент пришёл с сайта;
- `email` — почта в блоке заявки и футере;
- `SOCIALS` — заполните `url`, и иконка сама появится в футере. Пустые не показываются.

## Тексты и языки

Все тексты — в `js/i18n/ru.js`, `kk.js`, `en.js`. Ключи во всех трёх файлах одинаковые.

- Язык выбирается кнопками ҚАЗ / РУС / ENG и запоминается в браузере.
- Ссылка на конкретный язык: `/?lang=kk`, `/?lang=en` (удобно давать иностранным клиентам).
- Русский текст продублирован прямо в `index.html` — так его видят поисковики и пользователи без JS.

После правки текстов запустите проверку (нужен Node.js 18+):

```bash
node scripts/i18n.mjs        # все ли ключи есть во всех языках и совпадает ли HTML с ru.js
node scripts/i18n.mjs --fix  # переписать русский текст в index.html из ru.js
```

Добавить новый язык: скопируйте `en.js` в, например, `de.js`, переведите, добавьте `'de'` в
`LANGS` и загрузчик в `js/i18n.js`, кнопку в `.lang-switch` в `index.html` и строку `hreflang`.

## Портфолио

Проекты лежат в `data/projects.json`. Секция «Работы», пункт меню и кнопка «Смотреть работы»
появляются автоматически, как только в файле есть хотя бы один проект без `"draft": true`.
Пока проектов нет — секции на сайте просто не видно.

Добавить проект = добавить объект в массив:

```json
{
  "id": "salon-app",
  "draft": false,
  "type": "mobile",
  "image": "assets/img/projects/salon-app.webp",
  "title":       { "ru": "Приложение для салона", "kk": "Салонға арналған қосымша", "en": "Salon app" },
  "description": { "ru": "Задача: ...",           "kk": "Міндет: ...",               "en": "Task: ..." },
  "result":      { "ru": "Что получилось: ...",   "kk": "Нәтиже: ...",               "en": "Outcome: ..." },
  "stack": ["Flutter", "FastAPI", "PostgreSQL"],
  "links": {
    "appstore": "https://apps.apple.com/...",
    "googleplay": "https://play.google.com/store/apps/details?id=...",
    "github": "",
    "demo": ""
  }
}
```

- `type`: `mobile`, `backend` или `bot` — по нему работает фильтр (кнопки фильтра появляются,
  когда типов хотя бы два).
- Текстовые поля можно писать строкой (`"title": "Salon app"`) — тогда она одна на все языки.
  Если нет перевода, показывается русский.
- Пустые ссылки не показываются.
- `"draft": true` — проект скрыт. Посмотреть черновики: откройте сайт с `?drafts=1`.
  В файле сейчас лежит один черновик-пример — удалите его, когда добавите настоящие проекты.

## Как заменить картинки

Картинки подставляются **автоматически по имени файла**: положите файл в нужную папку — и он
появится вместо плейсхолдера. Пока файла нет, на его месте аккуратная заглушка с подписью
слота и размером. Пропорции зафиксированы, так что вёрстка не «прыгнет».

| Слот | Файл | Размер, px | Пропорции | Где |
|---|---|---|---|---|
| Главная иллюстрация | `assets/img/hero.webp` | 1200×1200 | 1:1 | Первый экран |
| Услуга: мобильные | `assets/img/services/mobile.webp` | 600×450 | 4:3 | Карточка услуги |
| Услуга: backend | `assets/img/services/backend.webp` | 600×450 | 4:3 | Карточка услуги |
| Услуга: боты | `assets/img/services/bots.webp` | 600×450 | 4:3 | Карточка услуги |
| Услуга: MVP | `assets/img/services/mvp.webp` | 600×450 | 4:3 | Карточка услуги |
| Услуга: поддержка | `assets/img/services/support.webp` | 600×450 | 4:3 | Карточка услуги |
| Почему мы / команда | `assets/img/about.webp` | 1200×800 | 3:2 | Секция «Почему мы» |
| Превью проектов | `assets/img/projects/<id>.webp` | 1200×750 | 16:10 | Портфолио (путь в `projects.json`) |
| Фон заявки (по желанию) | `assets/img/cta-bg.webp` | 1920×800 | 12:5 | Секция с формой |
| Превью для соцсетей | `assets/img/og-image.png` | 1200×630 | — | Ссылка в Telegram, WhatsApp, соцсетях |
| Логотип | `assets/img/logo.svg` или `logo.png` | 512×512 | 1:1 | Шапка (рядом с надписью EasyCode) |

Советы:

- **Сжатие в WebP.** ChatGPT отдаёт PNG на несколько мегабайт. Откройте [squoosh.app](https://squoosh.app),
  перетащите файл → справа выберите **WebP**, качество 75–82 → **Resize** до размера из таблицы
  → Download. Цель: hero и about — до 150–200 КБ, карточки услуг — до 60–80 КБ.
- `og-image.png` оставьте в PNG или JPG: не все мессенджеры понимают WebP в превью.
- Фон заявки лучше делать тёмным и «спокойным» — поверх него текст и форма; сайт дополнительно
  затемняет картинку.
- **Мобильная версия hero/about** (по желанию): положите `hero-mobile.webp` / `about-mobile.webp`
  и раскомментируйте строку `<source ...>` внутри `<picture>` в `index.html`.
- **Логотип**: когда появится `logo.svg`/`logo.png`, он встанет в шапку слева от текста «EasyCode».
  Если ваш логотип уже содержит название и текст не нужен — удалите `<span class="logo__word">…</span>`
  в шапке `index.html`. Favicon (`assets/favicon.svg`, `apple-touch-icon.png` 180×180) тоже
  можно заменить своими.
- Пока картинок нет, в консоли браузера будут ошибки 404 на эти файлы — это нормально,
  они исчезнут, как только вы положите файлы.

## Защита формы от спама

- **Honeypot** — скрытое поле `website`: люди его не видят, боты заполняют. Такие заявки молча отбрасываются.
- **Проверка времени** — форма, отправленная быстрее чем за 3 секунды после загрузки, считается ботом.
- **Ограничение частоты** — не больше 5 заявок с одного IP за 10 минут. Счётчик живёт в памяти
  функции, поэтому это мягкая защита. Для строгого лимита подключите Upstash Redis / Vercel KV.
- **Cloudflare Turnstile** (когда понадобится):
  1. Создайте виджет в Cloudflare → Turnstile, получите site key и secret key.
  2. В `index.html` подключите `<script src="https://challenges.cloudflare.com/turnstile/v0/api.js" async defer></script>`
     и вставьте `<div class="cf-turnstile" data-sitekey="ВАШ_SITE_KEY"></div>` на место комментария `[TODO: Turnstile]` в форме.
  3. В `js/form.js` добавьте в payload `turnstileToken: form.querySelector('[name="cf-turnstile-response"]')?.value`.
  4. В Vercel добавьте переменную `TURNSTILE_SECRET` — функция начнёт проверять токен автоматически.

## Что заполнить перед запуском

Поиск по проекту: `grep -rn "TODO" --exclude-dir=node_modules .`

- `js/config.js` — ссылка на бота, email, соцсети.
- Цены в карточках услуг (`от [TODO] ₸`) — в `js/i18n/ru.js`, `kk.js`, `en.js`, затем `node scripts/i18n.mjs --fix`.
- Процент предоплаты `[TODO: 30–50]` и срок гарантии `[TODO: N]` — там же (процесс и FAQ).
- Проверить сроки «от 6 недель / от 3 недель / от 1 недели / от 4 недель / от 1 месяца» — в услугах и FAQ.
- Диапазоны бюджета в форме — `index.html` (`<select name="budget">`), словари и `BUDGETS` в `api/lead.js`.
- Домен `https://easycode.kz` — `index.html`, `robots.txt`, `sitemap.xml`.
- Казахский текст (`js/i18n/kk.js`) — показать носителю языка.
- Картинки — по таблице выше.
